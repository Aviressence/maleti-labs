# Vektör Toplama

*Fizik 1 · Hafta 1 · Vektörler*

Adres: https://maletilabs.quatressence.dev/sims/vektor-toplama

İki vektör düzlemde sürüklenir; toplam veya fark uç uca ya da paralelkenar yöntemiyle çizilir, bileşenler ve sonucun büyüklüğü/açısı hesaplanır.

## Ayarlar
- A ve B vektörlerinin uçları (sürükleme)
- Yöntem: uç uca / paralelkenar
- İşlem: A + B / A − B
- Bileşen tablosu

## Formüller ve kurallar
- Değişme: $\vec A + \vec B = \vec B + \vec A$; birleşme: $(\vec A + \vec B) + \vec C = \vec A + (\vec B + \vec C)$
- Bileşenler: $R_x = A_x \pm B_x,\ R_y = A_y \pm B_y$
- Üçgen eşitsizliği: $|\vec A + \vec B| \le |\vec A| + |\vec B|$
- Fark: $\vec A - \vec B = \vec A + (-\vec B)$; sıra önemlidir.

## Bağlantı parametreleri
Ayarlar adreste saklanır; paylaşılan bağlantı aynı ayarlarla açılır: `ax`, `ay`, `bx`, `by`, `yontem` (tail | para), `islem` (add | sub), `bilesen` (0 | 1).
